## العوائق الخارجية المحددة
- `docker` و`supabase` CLI غير مثبّتين على الجهاز، ولم تُمرَّر متغيرات مشروع Supabase مستضاف بعد؛ لذلك أُضيف خادم محلي متوافق (`scripts/local-supabase.mjs`) يعمل على PostgreSQL الحقيقي (PGlite) ويشغّل الترحيلات وRLS وJWT الحقيقية لتجربة التطبيق محليًا الآن، ونفس الكود يتصل بأي مشروع Supabase مستضاف بتغيير `.env.local` فقط.
- `SOCIALAPIS_API_KEY` غير مضبوط في البيئة؛ لم تُنفَّذ السحبة الحية و0 Credits مستهلكة.
- مستودع مرجع X الأقدم (`Enes830/fetshingaccouts`) يعيد HTTP 404 (غير متاح للقراءة). نموذج X مختبر محليًا بعينة اصطناعية معلّمة داخل `tests/` فقط.
